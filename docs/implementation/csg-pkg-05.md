## Planning and assessment entry

My Classes groups the existing pathway, practice requirements and pacing editors under Plan. The editors link back to the selected class and Plan. Class assessment links open the existing Workplace Readiness builder with the chosen assessment type and active class context. The global Practice & Assessments section, anonymous mode, aggregate report privacy thresholds, and Canvas QTI remain available.

The authenticated requirements editor uses Save Draft → Preview Saved Draft → Publish. Preview reads the exact persisted version and displays the shared student preview. A subsequent edit or save invalidates the preview. The service rejects stale publication, and the editor warns on page exit with unapplied or unsaved changes. Requirements display revision history and the existing pacing editor keeps the rollback workflow. Restoring stages a draft and needs preview and publish to create a new revision. The existing standalone requirements demo retains its local simulation.
