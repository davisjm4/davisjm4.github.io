# Acceptance scenarios

**Specification for future validation.** These tests describe required outcomes and proposed checks. A baseline observation is historical evidence. Record new runs by requirement, commit, environment, device, outcome and evidence. Use the [isolated full-role environment](https://github.com/davisjm4/davisjm4.github.io/tree/audit/full-role-ux-environment) or an equivalent isolated fixture. No real class records are needed.

## Teacher-directed learning

Fixture: two authorized teachers with distinct classes, one class of at least 24 synthetic profiles, a student with saved map selection and partially answered practice, one class-wide assignment for skill/area B, one individual assignment for A, a separate selected-group item and unrelated destination C. Use both activation orders. Exercise focused skill, area, group and supported activity targets. Compare desktop, tablet and phone, and use keyboard-only switching and release.

| Test ID | Setup and steps | Required outcome |
| --- | --- | --- |
| CSG-AT-TDL-01 | Publish individual A and class B in both orders. Add a same-target group or individual assignment. | Today's Classwork appears first. Catch-up remains available. Shared targets show one recommendation with independent assignment status. |
| CSG-AT-TDL-02 | Select an answer in Array Lab Reverse. Publish a new Loop Lab class assignment while the student is working. Switch labs and return, then refresh. | The new assignment leaves the active screen and input in place. Loop Lab opens and works. The original Reverse question and selection return in the same tab. |
| CSG-AT-TDL-03 | Save an independent map position, complete assigned work, and use Resume Previous Path and Continue From Here. | Both actions land at the intended position. Assignment status and ordinary navigation remain independent. |
| CSG-AT-TDL-04 | While assigned, open an unrelated lab by class Map, List, search or direct URL. Change mode within the same lab. Dismiss Continue Here by keyboard. | The reminder is nonblocking and stays dismissed as the student answers further questions. Direct entry and all ordinary modes remain available. |
| CSG-AT-TDL-05 | Edit, end or cancel an assignment and try a stale revision and retry. Excuse one recipient. | Changes are versioned and idempotent. Other assignments, recipients and evidence retain their prior state. |
| CSG-AT-TDL-06 | Submit a matching independent response with an assignment start receipt, an off-target response, an assisted response, and an unassociated valid legacy response. Replay the same batch. | Only the matching eligible response completes that assignment. Ordinary valid practice follows the existing evaluator. Replays never add a second evidence record. |
| CSG-AT-TDL-07 | Preseed qualifying practice and an official 4/4. Issue, edit, complete and excuse an assignment. | Original practice and mastery records remain intact. Only the authorized teacher assessment can change the official result. |
| CSG-AT-TDL-08 | In a 24-profile class, preview and publish individual and class work. Review counts and try another teacher, student and stale credentials. | Owner sees assignment status. Unauthorized actions fail without disclosure. Students receive their own assignment details. |
| CSG-AT-TDL-09 | Schedule and cancel work. Compare individual, selected group and dynamic class membership. | Work appears at the scheduled time. Class membership remains dynamic, selected recipients stay scoped, and stale or revoked membership cannot write private records. |
| CSG-AT-TDL-10 | After loading a lab, disconnect Wi-Fi, generate and answer several questions, change mode, then reconnect. Test an already available activity and guest entry on a shared browser. | Locally available practice continues. Queued attempts sync once, and guest work stays separate. Only supported assignment context earns completion. |
| CSG-AT-TDL-11 | Submit a matching response through its assignment and then an unsupported response. Complete unsupported work through authorized teacher review. | Completion source is recorded separately from proficiency and official mastery. |
| CSG-AT-TDL-12 | Excuse one student from whole-class work and retry. Compare both profiles and the history. | The excused assignment leaves that student's active work. Other students and prior evidence are unaffected. |

## CSG-AT-15 — Direct activity navigation

From a fresh guest chooser, select AP CSP, Data and RGB: practice opens in three selections. Repeat ASCII; Binary appears once and retains all three skill IDs through internal controls. Repeat representative Advanced CS, Robotics and WPR activities. A synthetic multi-game area retains a meaningful activity choice. Check Map/List, legacy continuation aliases, source-map return, scroll/zoom, next required activity, completed circle/check and optional Level 4. Compare displayed activity and skill denominators against the same pathway data. Verify individual class skill assignment/override and excluded-skill behavior, immutable prior evidence and attempts, guest isolation, offline/recovery/archived-class regressions. At 320/390/768/1024/1366 CSS px verify natural default scrolling, no horizontal clipping and reachable touch controls. RGB exact conversions and channel reasoning may contribute audited evidence; visual matches, visits, skips, assistance, retries and unknown metadata must not establish proficiency. Keep teacher-reviewed mastery and configured policies intact.
