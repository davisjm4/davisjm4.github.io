# Student experience

## CSG-STU-01 — Independent start and persistence

**Approved · implemented in part. Roles:** guests, enrolled students using independent practice. Start from course selection, open the full course map, search and explore any practice-ready skill. Make the scope clear before launch, including limits on tracking. Present one contextual recommendation with a plain reason. Keep progress and backup accessible in My Session or Independent History. Self-reported familiarity grants no proficiency, unlock, mastery, or evidence. Remove proficiency-like familiarity controls from primary skill actions. Optional private notes or pins require approval.

**States/data:** new, resumed, paused saving, storage unavailable, backed up, restored, practice-only. Guest history stays in the browser. Imported backups use validation and dedupe and remain unverified. Enrolled browsers can explicitly use guest practice with separate attribution. **Dependencies:** CSG-NAV-01/02, CSG-SES-02, CSG-SEC-02. **Accessibility:** no account modal blocks a guest, recovery copy and actions have accessible labels. **Acceptance:** start, practice, return and reload without an account. An eligible mapped answer appears once. An unsupported activity communicates its scope at launch and result. Familiarity or backup cannot create verified records.

## CSG-STU-02 — Join, restore and enter class

**Approved · implemented in part. Roles:** enrolled student. A class invitation shows class context, Join, and how to keep the recovery credential. Existing profiles restore with a pseudonymous ID and secret. Show enrollment and restoration as distinct tasks. After sign-in, provide My Class with assigned work, class progress, resume, and account actions. Pacing targets clearly distinguish suggested dates from assignments or deadlines. **States/data:** invitation valid/expired, join success, credential saved, restoring, invalid, revoked, offline and no class. Authenticated progress syncs by authorized profile. Keep recovery out of logs and reports. **Dependencies:** CSG-SEC-01, CSG-NAV-01. **Accessibility:** labeled inputs and status, focus on actionable errors, paste allowed. **Acceptance:** enroll in each registered course with a synthetic identity, restore on another browser, and observe only that profile's data. Invalid links and expired sessions offer safe recovery.

## CSG-STU-03 — Skill details and progression

**Approved direction · partial. Roles:** guest and enrolled. Prioritize the skill name and official teacher-reviewed result if present, next meaningful action, then provisional practice and requirements details. Display formative level, teacher practice target and teacher-reviewed score as separately labeled facts. Explain the eligible evidence window and distinguish missing evidence, low accuracy, requirement met and verified mastery. Level 3 is sufficient to progress, and Level 4 is optional. Practice-only activities or unsupported levels explain available evidence routes. Keep Map/List and a clear Back to Course Map. **States/data:** not started, practice only, eligible evidence, goal met, verified result, review due and no coverage. Course and skill selection restore independently of scores. **Dependencies:** CSG-MAS-01/02/03, CSG-UX-02, CSG-NAV-03. **Accessibility:** mobile detail sheet or page remains dismissible and focuses the selected skill. **Acceptance:** a teacher-reviewed 4/4 appears above a lower formative result with both interpretable. Students can move on at Level 3 and access optional Level 4 without implying an official score.

## CSG-STU-04 — Assigned-work presentation

**Approved · planned. Roles:** enrolled. Follow CSG-TDL-02/04. **Today's Classwork** precedes **Your Catch-Up Work**, with no forced order and one recommendation for a shared target. Both assigned destinations remain available under overlapping restrictions. Allow switching while preserving each attempt and prior pathway position. Offer Resume Previous Path and Continue From Here when applicable. Maintain the same order on desktop, tablet and mobile, with classwork first and catch-up accessible directly below.

**States/data:** no work, only class, only catch-up, both, active restriction, pending notice, completed or previous path temporarily blocked. A notice must preserve in-progress input. **Dependencies:** CSG-TDL-01–04, CSG-MAS-04, CSG-UX-03. **Accessibility:** labeled sections, prominent Start/Resume, meaningful status and no focus steal. **Acceptance:** run CSG-AT-TDL-01 through 03 and verify both entry paths use the same proficiency behavior.
