## How diversity is counted

Surface variety and reasoning variety are measured **separately**. A new seed, a new fictional name, new numbers, a different evidence-pair order or a shuffled answer order never counts as a new problem.

| Layer | What makes two challenges "the same" |
|---|---|
| Exact | Identical prompt, passage, seven sentences, options and target |
| Passage | Identical source passage |
| Surface | Same kit, same fictional name and same numbers |
| Scenario | Same kit and same scenario elements (features, settings, stages, observations), ignoring the question |
| Configuration (question/claim) | Same reasoning structure applied to the same scenario elements. **This is the "meaningfully distinct configuration" counted below.** |
| Evidence relationship | Same two supporting facts, ignoring wording and question |
| Structure | Same reasoning structure (authored models count as `authored:<family>`) |
| Mode/target | Same practice mode and target role |

- **No exact repeat and no configuration repeat occurs in the first 20** questions of any topic and difficulty.
- **Exact repeats within 100** (worst 2) are all authored models, whose fixed passages vary little. Generated challenges had **0** exact repeats in every 100-question session.
- **Configuration repeats at 50 and 100 are expected.** A single topic and difficulty has 24–45 configurations, so a 100-question session on one topic must revisit them. Revisits use a new fictional name, new numbers, new passage filler and a new target role or mode, and the game labels them "Review practice".
- **Evidence-relationship repeats** (worst 4 in 20) count cases where two *different* questions rely on the same two facts, for example "How do these two features help?" and "Why is it suited to this setting?". These are different claims and explanations but the same supporting facts. Per topic and difficulty there are 21–32 distinct evidence relationships, fewer than configurations. Up to 3 evidence relationships per combination are shared by more than one structure.
