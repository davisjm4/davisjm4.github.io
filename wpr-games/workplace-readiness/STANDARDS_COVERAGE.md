# Standards coverage

Workplace Readiness Games is an **independent practice resource** aligned to the publicly published Workplace Readiness Skills (WRS) module pages of the Career and Technical Consortium of States (CTECS), reviewed 2026-10-18 at <https://wrs.ctecs.org/practice/>. It is not an official CTECS product, uses no official, retired or purchased assessment questions, and does not guarantee results on any assessment. All scenarios, options and feedback are original.

The module pages for each skill list the concepts a student should be able to demonstrate. Each is recorded here as a stable **concept ID** (`skill-id:concept`), and every template declares the concepts it assesses. The validator rejects templates that cite unknown concepts, so this mapping is checked, not decorative.

Definitional bullets ("defining integrity", "defining diversity", etc.) are **not** assessed directly, because the platform teaches applying skills in situations rather than recalling vocabulary. They are listed per skill under *Not assessed directly*.

## Known gaps

- **No Advanced template yet** for: . Choosing one of these skills with *Advanced* difficulty shows a "no challenges match" message instead of an empty or wrong game.
- Advanced is 22% of templates, below Beginner (34%) and Intermediate (44%).
- Each reasoning family currently holds about one template, so each skill has 5 to 8 distinct reasoning patterns. See REASONING_DIVERSITY_REPORT.md.
- Legal, financial and jurisdiction-specific content is deliberately limited. Where a rule decides the answer, the rule is stated inside the scenario; no template teaches a real tax rate, law or regulation as fact.
