Search & Sort Lab

Trace binary search, selection sort, insertion sort, and merge sort one step at a time. Every challenge is generated fresh, so you can practice as long as you like.

Conventions used here
Binary search
mid = (low + high) / 2 (integer division). Returns the first match its midpoints reach, which is not always the first or last duplicate.
Selection sort
One swap per pass (even with itself). Strict <, so ties keep the earlier index.
Insertion sort
Elements > key shift right (one write each). Equal elements do not shift. A shift is not a swap.
Merge sort
mid = (lo + hi) / 2, so the left half is larger for odd sizes. Ties go to the left. Each a[i] <= a[j] test is one comparison.
