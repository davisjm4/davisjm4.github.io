Inheritance & Polymorphism Lab

Build hierarchies, trace which method really runs, and fix inheritance bugs — the reference type decides what compiles; the object decides what runs.

Key terms
Superclass / subclass
class Truck extends Vehicle: Truck is the subclass. A class extends exactly one class (Object if none is written).
Inherit
A subclass gets its superclasses' non-private methods without rewriting them. Constructors are not inherited.
Override
Same name and parameter types as an inherited instance method. @Override asks the compiler to confirm it.
Overload
Same name, different parameter types — a separate method.
Reference type vs. object type
In Vehicle v = new Truck(); the compiler checks Vehicle; at run time Truck's version of an overridden method runs.
abstract
An abstract class can't be created with new. An abstract method has no body; concrete subclasses must implement it.
