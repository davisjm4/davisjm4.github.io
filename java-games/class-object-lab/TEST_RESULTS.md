### What the generator part asserts (per challenge, 39,000 challenges)

Deterministic per seed; mode, difficulty, game id and topic metadata; four distinct choices with exactly one keyed answer; no `undefined`/`NaN` in any text; structurally valid program; each distractor carries a documented misconception and an explanation; output answers re-derived by a fresh simulation; prompt does not reveal the answer. Per cell: χ² on answer positions; key uniquely longest < 40% and uniquely shortest < 40%; ≥ 20 reasoning configurations (asserted when the sample has ≥ 400 challenges).

### Semantics part

Five counterfactual pairs change the answer, the signature, and the recomputed distractors, and are confirmed on the JVM. Invariants checked after every statement for 1560 challenges: every reference points to an existing object, every object belongs to a declared class, instance fields belong to their class and hold their declared primitive type, and execution stays within the step bound. Boundary programs: zero value, negative rejected, boundary accepted, null printed, null dereference, three aliases, parameter reassignment, returned reference, equal state, different objects, shared static state, constructor default.

## Problems found by testing and fixed

- **Length cues** (1,000-per-cell run): the key was the uniquely longest choice in 48.5% of Beginner toString questions and the uniquely shortest in 80–90% of the Intermediate/Advanced uninitialised-local questions. The choice texts were rebalanced, a general length-balancing step was added, and both checks are now asserted.
- **Trivial keys:** "which comparison is true" could be answered by a bare `x != null` on a live variable. Such comparisons are now used only as distractors.
- **Incoherent misconception output:** the defaults-to-null model applied to `+=` produced `0`. Arithmetic on null now discards that model run.
- **Crowded-out readings:** alternative-program misconceptions (boundary, ignored computation, argument order) ranked below every simulator flag and rarely appeared. They now compete in the middle of the ranking.
- **Mobile overflow:** object cards (minimum width 10rem in a fixed two-column grid) scrolled the page sideways at 390 and 360 px. Fixed with a responsive grid.
- **Generation budget:** about 1 in 300 Advanced equality seeds needed more than 120 attempts. The deterministic budget is now 400 (worst case observed: 144).

## Not tested

- Browsers other than Chromium (no Safari, Firefox, physical Chromebook, or screen reader). Accessibility is covered only structurally: radio-group roles, `aria-checked`, focus outlines, a labelled code region, and a text alternative for the diagram.
- No educator or student has reviewed the generated content. The 195-sample manual review in GENERATED_SAMPLES.md was done by Claude.
- The difficulty bands are a model of complexity, not calibrated against student performance data.
