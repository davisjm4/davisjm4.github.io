Key terms
Parameter
A variable declared in a method or constructor signature, such as int price.
Argument
A value or expression supplied in a call, such as 12 in addBonus(12).
Return type
The type declared before an ordinary method's name. void means no value is returned.
Constructor
A class member used with new to create an object. Its name matches the class and it has no return type, not even void.
public / private
public members can be used from other classes; private members can be used only by code inside their own class.
