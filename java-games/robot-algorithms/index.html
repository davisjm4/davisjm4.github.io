Robot Algorithms

Predict, build, and debug short Java programs that steer a robot across a grid.

Robot rules
  • (Row 0, Col 0) is the top-left cell. Rows increase downward; columns increase to the right.
  • robot.move() advances one cell in the facing direction. Moving into an obstacle or off the grid stops the program with a movement error.
  • The robot faces Up, Right, Down, or Left on the screen; the yellow point shows which way. robot.turnLeft() turns it a quarter-turn counterclockwise and robot.turnRight() a quarter-turn clockwise, from the way it is facing now.
  • For "where does it finish" questions, click a cell to move the robot there, and click the top, right, bottom, or left side of the robot's cell to make it face that way, then submit.
  • robot.canMove() is true when the next cell is open (not an obstacle, not off the grid). robot.atGoal() is true when the robot is on the goal.
  • Code runs inside the robot's program, not as a standalone Java application. Programs stop after 2,000 steps to prevent infinite loops.
