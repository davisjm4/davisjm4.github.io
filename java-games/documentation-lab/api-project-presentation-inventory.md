# API Project Builder presentation inventory

Development inventory for the nine integrated scenarios. Counts compare all endpoint parameters in the first accepted plan with the number of student-facing parameter controls in that same plan. A field-mask selector or dependency selector is one conceptual decision even when it contains multiple checkboxes. Endpoint selection is additional to these counts. Other accepted plans remain in the verified content library.

The verified `api-project-data-v1.json` endpoint definitions are unchanged. The separate `api-project-presentation.js` map determines which parameters are assessed, automatically supplied, or hidden for this project; the technical documentation remains available in a collapsed section. Hidden optional parameters are omitted, not given invented defaults.

The shorter one-decision projects intentionally retain their simple endpoint-selection problem. No arbitrary resource ID, search term, photo size, or coordinate is assessed. Choices such as a field mask are not preselected. Each scenario retains multiple plausible endpoint cards, including documented distractors and access restrictions.
