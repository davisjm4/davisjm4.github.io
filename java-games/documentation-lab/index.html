Key terms
// … single-line comment
Runs to the end of the line. Good for short notes inside a method.
/* … */ block comment
Can span several lines. Ignored by the javadoc tool.
/** … */ Javadoc comment
Placed right before a class, method, or field. Tools turn it into API documentation pages.
@param name
Describes one parameter in the method's signature (not a field).
@return
Describes the value returned. Not used for void methods.
@throws Type
Names an exception the method can throw and the condition that causes it.
Precondition
Something that must be true before a method is called for it to work correctly.
