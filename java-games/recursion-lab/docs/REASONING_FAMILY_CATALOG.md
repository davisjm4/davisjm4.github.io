# Reasoning-family catalog

Generated by `tests/gen-docs.mjs` from the live generators. The **legacy** generator of each mode is retained as one weighted entry (only narrow changes: merge-sort questions now use unsorted input; legacy debug items display 'find the bug' instead of their answer-revealing family label) (weights: base 1, returns 1.5, output 1.5, arrays 2, debug 0.75, searchsort 1.5; each new family has weight 1, `knob-bug` 4).

Declared reasoning ids have the form `family:structural-variant:question-type`. Counts below are distinct ids observed in 600 builds per family and difficulty.
