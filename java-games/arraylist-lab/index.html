ArrayList Lab

See how each ArrayList operation changes the list’s contents, size, and indices — one decision at a time.

Quick reference
add(e)
Appends e at the end. Size grows by 1.
add(i, e)
Inserts e at index i (0 to size()). Elements from i on shift right.
get(i) · set(i, e)
Read / replace the element at index i (0 to size() − 1). set returns the old element; size does not change.
remove(int i)
Removes by position, returns the removed element. Later elements shift left.
remove(Object o)
Removes the first element equal to o, returns true/false. For an ArrayList<Integer> use Integer.valueOf(5).
size() · isEmpty()
Number of elements · whether size() is 0. Arrays use length instead.
indexOf(o) · contains(o)
Index of the first match (−1 if none) · true/false. Both compare with equals().

Assume import java.util.ArrayList; is at the top of the file.
