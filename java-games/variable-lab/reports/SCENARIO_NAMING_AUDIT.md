# Assemble scenario naming audit

All 105 authored scenarios in 21 existing families were reviewed. Each intended identifier describes its requested information. Within each family, all four possible sibling-name distractors refer to distinct properties. No ambiguous alternate dropdown names were found; no wording changes or content expansion were needed.

Accepted names are explicit: the existing canonical item.name, plus item.acceptedNames only if deliberately authored. The current catalog has no accepted aliases. A synthetic alias test verifies that explicit alternatives remain supported.
