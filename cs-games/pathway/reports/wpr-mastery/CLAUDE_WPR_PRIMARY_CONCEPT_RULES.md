# Workplace Readiness primary assessed concept rules

Commit `ac56e605bc0b86ab03b1a8ffc9ab91bddd95cb07`. Source of truth: `cs-games/pathway/wpr-primary-concepts.mjs` (table) and `cs-games/pathway/mastery/wpr-automatic.mjs` (enabled skills).

## Rules

1. **One scored response credits at most one skill.** The credited skill is the primary assessed concept of the question's reasoning unit.
2. **The reasoning unit decides, never tag order.** An authored template is one unit (`a:<templateId>`). A composed question's unit is its kit and decisive rule (`c:<kit>/<rule>`), because the rule is the judgement the correct answer requires.
3. **The primary must be one of the question's own tags.** A table entry that names a concept the question does not carry is refused at run time.
4. **Secondary tags keep every instructional use** (topic discovery, feedback, recommendations, related skills, search, teacher reports through the legacy event) and never earn node credit. They are not sent in the node event.
5. **No reviewed primary means no node credit.** Generic reasoning shared across kits, units whose tags are demonstrated together, and unknown units earn nothing. Practice and legacy reports continue.
6. **Hazard control credits a safety concept only in a safety or equipment kit.** In a customer-service or teamwork kit the same rule tests safety, which is not one of that kit's tags, so it earns nothing.
7. **The server verifies.** The client names the unit and the concept; the server credits the node only if the table gives that concept for that unit and the skill is enabled. Client-supplied node ids are ignored.
8. **A skill is enabled only if its question bank passes the activation rules** (see the audit) **and it is not a performed behaviour** (8 concepts, `WPR_PERFORMANCE_ONLY`). Otherwise it stays teacher-assessed, even though a reviewed primary exists.
9. **Multi-skill credit is not supported.** No question contains independently scored parts, so no unit credits two skills.
10. **Confidence.** H: the unit's reasoning is the concept's behaviour. M: reasonable, but another tag of the same unit is defensible. At least 3 H units are required to enable a skill.

Example: `CON-D-001` (private conversation after public criticism) is tagged diplomatic-negotiation, work-style-differences and when-to-escalate. It credits `conflict-resolution:diplomatic-negotiation` only.

## What is not credited

- Composed rules in no kit's table: `proceed-when-satisfied`, `respect-dependencies`, `find-the-defect`, `protect-requirements`, `consult-affected-people`, `protect-safety`, `keep-safety-step`, `suggest-improvement-after`, and `control-hazard-first` outside `saf-*` and `jst-*` kits.
- Kits `mat-purchasing`, `mat-job-measures`, `mat-applied` (basic calculations and job-task math are demonstrated together).
- Authored templates left ambiguous: `CTP-O-001`, `ILI-O-001`, `MAT-F-001`, `MAT-F-002`, `MAT-N-002`, `MAT-O-002`.
