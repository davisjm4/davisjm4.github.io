## Evidence review

The adapter queues one event for the primary concept attached to the scored reasoning unit. The original WPR report event still runs. Automated synthetic checks cover correct and incorrect first attempts, later attempts, replay, guest isolation, Mixed Practice, secondary tags, unknown units, teacher-reviewed records and existing class reports. Negative controls detect first-tag attribution, all-tag attribution, and accepting mismatched pairs. The attribution table leaves generic cross-kit hazard, ordering and defect rules uncredited. Numerical variants and multi-step items require a stated dependency and a single assessed decision before gaining credit.

The server currently checks the requested concept against the client-supplied reasoning key. Using the same synthetic question ID, the normalizer accepted both `a:CON-D-001` with `conflict-resolution:diplomatic-negotiation` and a complete replacement with `a:LIS-D-001` and `listening-and-speaking:active-listening`. Mixing the first key with the second concept earned zero node credit. These were separate normalization calls before database deduplication. The first submission can therefore carry a different valid pair. The Worker also accepts the client correctness flag. Before release, tie the accepted reasoning unit and score to a verifiable question presentation, then test pair substitution, invented presentations, changed scores, and offline retry. The supplied tests do not establish that stronger guarantee.

The remaining 64 skills have distinct dispositions: 2 option-length repairs, 50 coverage or attribution reviews, 8 teacher-assessed performed behaviors, and 4 without primary content. See the [next content package](WPR_NEXT_CONTENT_PACKAGE.md).
