# Teacher Tools UX redesign: screenshots

Real rendered pages (Chromium, deviceScaleFactor 2) from the local development service seeded through its real API
(a published class pathway with one unpublished edit, 5 student profiles, one archived class).
`before/` is unmodified `main`; `after/` is this branch. Widths: mobile 390, tablet 768, desktop 1280.
Numbering matches between sets (01 Teacher Tools signed out, 02 class and students, 03/04 pathway editor signed out/in,
05 learning goals/nodes, 06 review and publish). Files with a letter suffix (02b, 02c, 05b) are new views that did not exist before.
Long pages are clipped to the top of each view.
