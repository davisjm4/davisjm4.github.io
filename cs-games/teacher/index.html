Build a practice quiz

Generate a small Canvas-compatible multiple-choice assessment from an existing game. Questions are created locally in this browser.

Quiz settings

Choose one or more games. Use Ctrl (Windows) or Command (Mac) to select multiple entries.

Modes are grouped by source. Visual, drag-and-drop, and non-four-choice activities are excluded.

R-A-C-E-C-E-S writing filters

Choose one subject, then optionally select one or more topics. Leave all topic boxes unchecked to include every topic in the selected subject.

Workplace Readiness filters

Choose one or more skills and settings. Leave either list unselected to include all options.

For modes without difficulty controls, questions use the engine's native mixed level. If a mode offers only some levels, the nearest available level is used and shown in the preview. In Canvas, open Course Settings → Import Course Content, then import the downloaded QTI .zip and review the quiz.
