Assessment coverage and limitations

Some integrations cover selected interpretation modes: LinkedList exports tracing and collection decisions; Method & Constructor exports choices and source-span identification, not argument rearrangement; Documentation excludes comment editing, Javadoc construction, and multi-part classification; Inheritance exports native single-choice Abstract Class questions; API Response Explorer excludes multi-selection and classification; Robot Algorithms excludes route construction and repair tasks. Computing Impact items assess one labeled claim, evidence, or reasoning step. Cybersecurity exports single-warning phishing cases only. Algorithm Architect exports its existing missing-component format. Code Concepts excludes multi-region selection. Simulation exports reference questions, not live experiments. Trivial/Non-Trivial exports Program A classification. WPR and RACECES ordering remains recognition of a valid sequence.

RGB, ASCII, Dance, Network Breaker, Packet Router, Class Builder rearrangement, and API Project Builder remain interactive practice. Their complete manipulation or construction tasks do not have a validated standalone export in this package. The readiness pathway tracks practice evidence and has no question generator.
