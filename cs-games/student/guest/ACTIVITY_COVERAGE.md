# Activity coverage for independent learners

Generated by `build-coverage-matrix.mjs` from graph version 2026.11.10.1, the Java evidence registry, and a static scan of each activity page. Do not edit by hand.

An activity contributes local progress only when (1) its page imports a shared session tracker and (2) that tracker is one of the three that route first-attempt answers to the guest store. Everything else stays open for practice and says so on the page.

"Verified in real Chromium" means this activity is exercised in `tests/browser-tests.mjs`. The parity test (`tests/parity.test.mjs`) separately checks guest credit against the Worker for every skill selector in the graph.
