Learn / Reference — continuous and discrete information

Analog: a magnitude represents information by varying through intermediate values. A pointer can sit between scale marks; those printed marks do not restrict its position.

Digital: information is encoded using distinct permitted symbols, values or states. Computers commonly use bits (0 and 1). A number rounded to tenths can take 21.4 or 21.5, but its displayed representation cannot show all values between them.

Sampling selects measurement times. Quantization maps measured amounts onto permitted levels, such as integer codes. Sampling alone does not necessarily quantize amplitude: a sample-and-hold can retain an unrounded analog voltage. Questions about this distinction name the amplitude being classified.

Analog-to-digital conversion (ADC) measures a varying input and assigns numerical codes, typically using sampling and quantization. Distinguish the input signal from the output data.

Digital-to-analog conversion (DAC) turns codes into a physical output. The raw output may have steps; a reconstruction filter can smooth it into a varying waveform. Questions about reconstructed output specify the filtered signal rather than leaving that stage ambiguous.

A physical phenomenon can vary continuously while its recorded measurement is digital. A modern device can contain both kinds of representation. A paper-based code can be digital. Focus on what the question names.
