ASCII reference · 0–127

Learn / Help — bits, bytes and ASCII

A bit is 0 or 1. A byte contains eight bits and has 256 possible patterns, representing values 0–255.

From left to right the weights are 128, 64, 32, 16, 8, 4, 2, 1. Add only the weights whose bits are 1. To build a number, choose weights that add to it.

A = decimal 65 = binary 01000001. The 64 and 1 bits are set: 64 + 1 = 65.

ASCII assigns characters numeric codes 0–127. It uses seven bits of information, commonly placed in an eight-bit byte with the leading bit 0. Printable characters are 32–126. Values 0–31 and DEL (127) are nonprinting controls, including NUL (0), TAB (9) and LF (10). Values 128–255 are outside standard ASCII; this editor labels them instead of inventing characters.

Uppercase and lowercase differ: A is 65; a is 97. Spaces have a code too: SPACE is 32, not zero or an empty character.

Unicode covers many more characters and writing systems. UTF-8 encodes Unicode as bytes; ASCII characters use the same single-byte values in UTF-8. Many other Unicode characters need multiple bytes and cannot be entered as one ASCII character here.

The reference is always available. You are learning representation, not memorizing a code table. ASCII source: RFC 20.
