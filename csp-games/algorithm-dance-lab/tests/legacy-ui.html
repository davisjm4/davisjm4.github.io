    Compare abstraction · conceptual line counts
    These are the original worksheet’s conceptual counts, not the number of displayed code lines. Headers and braces count only inside the worksheet’s stated definition sizes. Executing the full dance still produces 50 movement instructions in every version.
    

    No functions
    10 verses × 5 movement-command lines. No definitions or calls.
    

    Separate body-part functions
    10 five-line definitions + 10 calls + one four-line hokey_pokey definition + 10 calls to it.
    

    Parameterized
    One five-line generalized definition + 10 calls + one four-line hokey_pokey definition + 10 calls to it.
    The separate-function worksheet version uses more lines than the expanded version because definitions and calls add overhead. Abstraction helps reuse and maintenance; it does not guarantee fewer lines. Combining all five moves in one generalized procedure is another valid design, with a different conceptual count.

    Movement guide & programming help
    moveIn brings the selected part forward or toward the center; moveOut returns that part toward its resting pose. shake oscillates the selected joint. For hips and shoulders these are stylized tilts. HEAD uses CENTER; paired parts use LEFT or RIGHT. turnAround makes one full turn and returns the limbs to rest.
    shake() with no arguments uses the most recently moved body part. This makes the no-parameter hokey_pokey() helper reusable. If no part has been moved, execution reports an error. shake(part, side) selects a part explicitly.
    Definitions do nothing until called. Parameter part and parameter side belong inside a parameterized definition; FOOT and RIGHT are example arguments supplied by a call. Repeat blocks may contain movements, procedure calls, or more repeats. Execution is bounded to 400 blocks, 800 movements and 16 nested procedure calls.
    The robot is constructed originally from low-poly shapes. Three.js r170 is bundled locally under its MIT license. No external assets, recorded dances, song recordings or music services are used. This release is silent.
    Pseudocode conventions follow the College Board reference sheet. Movement procedures are this game’s own vocabulary.
