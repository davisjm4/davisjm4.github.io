Reviewed 2026-10-25. Primary reference: [official CED](https://apcentral.collegeboard.org/media/pdf/ap-computer-science-principles-course-and-exam-description.pdf), Effective Fall 2023, still linked by the current course page. [August 2025 clarification](https://apcentral.collegeboard.org/media/pdf/ap-computer-science-principles-course-and-exam-description-clarification.pdf) checked; it changes introductory AP text, not these objectives.

Core means the concept is directly aligned with course content; it does not predict a specific exam word. Supporting means related explanatory vocabulary, not a separate required examination objective. Definitions and examples are original. 96 core concepts and 11 supporting terms.

Practice grouping follows the requested classroom contexts. Network security examples are grouped under Big Idea 4, while their official IOC objectives belong to Big Idea 5. Program-state and error examples can cross from Big Idea 1 into programming practice; data-privacy examples cross from Big Idea 5 into data practice. The table keeps these distinctions explicit.

## Supplementary primary references

- [TCP, RFC 9293](https://www.rfc-editor.org/rfc/rfc9293.html): reliable ordered byte stream and recovery mechanisms.
- [UDP, RFC 768](https://www.rfc-editor.org/info/rfc768/): datagram transport without its own delivery guarantees.
- [DNS, RFC 1034](https://www.rfc-editor.org/info/rfc1034/): distributed name-resolution roles.
- [HTTP semantics, RFC 9110](https://www.rfc-editor.org/rfc/rfc9110.html): application request/response semantics.
- [Creative Commons licenses](https://creativecommons.org/cc-licenses/): selected reuse permissions and conditions.
- [Open Source Definition](https://opensource.org/osd): source availability plus license rights, not mere public visibility.
