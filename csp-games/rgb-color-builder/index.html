Learn / Help — binary, hex, and RGB

RGB stands for Red, Green, Blue. A screen mixes these three kinds of light. Increasing a channel adds more of that light.

  • Each channel uses eight bits: 256 possible values, from 0 to 255. RGB uses 24 bits total.
  • Binary place values are 128, 64, 32, 16, 8, 4, 2, 1. Add the weights of the bits set to 1.
  • Hexadecimal uses 0–9 and A–F (A = 10 through F = 15). One hex digit represents four binary bits.
  • Two hex digits represent one eight-bit channel: the left digit × 16 + the right digit. For example, 80 = 128 and FF = 255.
  • Six hex digits represent all three RGB channels, in red, green, blue order: #RRGGBB.
  • Equal channel values produce shades of gray. Zero light is black; all three channels at 255 produce white.
