Trivial or Non-Trivial?

Trace what the pseudocode actually does. Decide whether a construct contributes meaningful work to the stated task.

Challenges use AP CSP Exam Reference Sheet notation and a bounded pseudocode subset for execution traces.

Meaningful / non-trivial in this game: the construct contributes task-relevant behavior, such as a decision, state change, repetition, output, or abstraction with a stated role.

Superficial / trivial in this game: the construct appears in the code but has no task-relevant effect under the full assumptions, even if it changes unobserved state.

These are instructional descriptions, not official College Board scoring categories. Behavioral change, useful work, task correctness, and meeting a specific AP Create requirement are separate judgments. Code can be meaningful and still be incorrect or miss a separate requirement.
