# Lossless vs. Lossy Compression Lab — implementation status

2026-10-24 · G-110 · Classroom/educator review pending.

## Audit and implementation

Compression Challenge provides lossless RLE text/pixel encoding and constrained size optimization. It does not provide the requested decision practice. Preserved its engine, route and controls; built a dedicated lab using the existing dark theme, two-choice interaction pattern, shared session/summary and bounded generator conventions. Related RGB, ASCII, Analog/Digital and numeric Binary Builder architecture was inspected.

Exactly Lossless and Lossy, no choice descriptions or preliminary reasoning. One scored selection; controls lock after either result. Feedback identifies the decisive requirement, artifact consequence/purpose and why the other method is unsuitable. Mixed default and four open topic filters; no difficulty levels. Generic Learn comparison is collapsed by default and does not react to the current question. Native keyboard controls, visible focus and status feedback; Next focuses the new scenario.

## Content and validation

60 authored contrasts (15 per filter), 120 fidelity cases, 360 compositions from transfer/storage/deadline profiles. All 18 coverage areas are tagged. Exact and approximate variants are scoped to the named artifact, which may differ between an original file and a view-only derivative. Every family supports both answers under its respective requirements, avoiding extension/device rules.

Classification is derived from a fidelity/feasibility model: exactly one of exact-required/loss-permitted; explicit priority; exact-retaining candidate fits in exact cases; in approximation cases the approved approximation fits while the available exact candidate exceeds the allowance. Contradictory flags, unspecified priorities, both-fitting ambiguous approximation cases, and infeasible cases are rejected. Sizes are hypothetical test results for these item/settings, not claims about universal codec performance.

The implementation audit found and repaired an initial paragraph-length shortcut. The best one-threshold word-count classifier now gets 203/360 (56.4%) correct; a <=60% guard is tested. Generated scenes contain neither method names nor codec extensions. Feedback stays hidden and empty until selection.

Authoring constraints, feasibility oracles and counterexamples support defensible choices; they cannot prove that every natural-language item is unambiguous to every student. Content review is developer implementation review, not independent educator certification. See CONTENT_REVIEW.md and source links: BJC compression https://bjc.berkeley.edu/bjc-r/cur/programming/4-internet/4-representation-compression/6-compression.html and College Board CED Topic 2.2 https://apcentral.collegeboard.org/media/pdf/ap-computer-science-principles-course-and-exam-description.pdf .
