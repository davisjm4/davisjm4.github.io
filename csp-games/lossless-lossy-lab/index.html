Learn / Help — compression decisions

Compression encodes information using fewer bits when the data and method permit it. Smaller files can reduce storage use and transfer time. Some inputs compress poorly or even grow because of encoding overhead.

Lossless compression permits reconstruction of the original information exactly. Repeating patterns or other redundancy can be represented efficiently without discarding the original information. Exact program files, records and archival masters often require this.

Lossy compression discards some information, so decoding cannot guarantee the exact original. For suitable media or approved lower-precision data, this often permits greater size reduction. The changes may be noticeable or imperceptible; losing information is not the same as always seeing or hearing a difference.

Fidelity means how closely reconstructed information matches the original. Decide what must survive: an editable program, a precise measurement, an archival master, or only a useful preview. A photograph, video, medical image or scientific dataset can have different requirements in different uses.

Storage and bandwidth limits matter, but do not override a stated requirement for exact recovery. A lossless method is not always larger than every lossy method. The trial sizes in these fictional practice scenarios describe only that item and its tested settings.

When a source file and preview are mentioned, classify compression of the named item. A retained original does not make its separately compressed approximate preview lossless.
