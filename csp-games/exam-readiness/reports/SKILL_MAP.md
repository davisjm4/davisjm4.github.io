# Curriculum and skill map

Version 1; 58 canonical skills. Create preparation reuses canonical IDs. The program uses Big Idea → Topic → Skill → recommended games. Multiple recommended games offer complementary bounded contexts; a question contributes to one skill only. Official CED, task handouts, August 2025 clarification and current exam guidance were reviewed. Supporting contexts (ASCII, RGB/hex, modern transport protocols, AI) are labeled; original projects, collaboration and written responses remain educator-reviewed work.
