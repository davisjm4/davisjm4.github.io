Existing storage: cspGames.session.v1 is a browser-local daily session. The schema retains optional student.name/student.period only in Session Summary; neither is copied. Daily reset uses local date; active time stops for hidden pages or after two minutes idle and uses a cross-tab lease. The pathway never adds active time. Algorithm Dance has an additional lesson-session store; TCP/UDP has a daily sidecar, and individual games have bounded repeat-history/draft keys. All are preserved.

No launch URL parameters are synthesized. Some games support exact challenge/share links, but those are not assumed to be skill filters. Each launch goes to its verified main route. Add mode/topic deep links only after testing the destination contract. All 31 routes are verified in live-game-links.txt. The consolidated catalog has its own topic labels; the pathway uses CED anchors rather than treating those navigation labels as official numbering.

Initial compatibility import preserves current available daily topic counts as aggregate estimated records, once. No previous erased days or detailed outcomes are invented. Daily resets and manual resets do not clear long-term pathway evidence. New first submissions are recorded before daily answer status changes; duplicate submission/retry events are excluded. Dance and ambiguous legacy topics remain available practice without fabricated skill evidence.
